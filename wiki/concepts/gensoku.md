# 源則

定義の正本: [canon/glossary.md](../../canon/glossary.md#hs-c-0008)

<!-- HS-DEF-QUOTE:BEGIN id=HS-C-0008 revision=2 source=canon/glossary.md -->
> **定義**: 源則とは、鼎の任意によらず、現し界に現れる物と事の変化と一定性を律する則である。
<!-- HS-DEF-QUOTE:END -->

## 導入

[鼎界](teikai.md)は鼎ごとに成立し、全員が一枚の世界を共有しているとは置かない。それでも、身体どうしが衝突し、測定が反復され、技術が働くとき、変化は各鼎の気分だけで好きに決まるわけではない。この「鼎界は共有されないのに、身体的・物理的な変化はなぜ整合するのか」という問いを引き受けるのが源則である。

源則は、世界の始点を説明する「原則」でも、第一原因を指す「元則」でもない。現し界に現れる[物](mono.md)と[事](koto.md)が、鼎の任意ではない仕方で変化し、また変化の中で性質を保つための則として置かれる。

## 要点

- 源則が律する対象は、現し界に現れる物と事である。
- 「律する」とは、命令者が外から支配することではなく、**均を立て、度を出だすこと**である。
- 源則は場所を持つ物ではない。「どこに在るか」ではなく「どのように効くか」で語る。
- 各鼎が共有するのは一枚の鼎界ではない。物理的整合の原理がいう共有は、現し界ではなく**律**である。
- 確認できる律の範囲は現に限る。玄り界まで律するか、源則が一つか、何に由来するかは未決である。

## 構造と働き

源則の語は、次の関係として読むと分かりやすい。

| 要素 | このページでの役割 | 確度と境界 |
|---|---|---|
| 源 | 変化の則が、鼎の任意ではないところから来ることを示す命名 | 宇宙の起源や第一原因を確定する語ではない |
| 則 | 何がどのように変化し、何が変化の中で保たれるかを記述する | 鼎に刻む銘との照応は【象徴的読解】 |
| 律 | 源則の働き。均を立て、度を出だす | 確認可能域は現に限る |
| 均 | 異なる現れを比較できる釣り合いを立てる側面 | 字義との照応は【象徴的読解】 |
| 度 | 測定や比較のための尺度を出す側面 | 字義との照応は【象徴的読解】 |
| 保つ | 変化を止めず、変化を通じて物の性質が続くことを説明する動詞 | 「固める」と同じではない |

源則から物理的整合の原理までは、次の順でつながる。

1. 各鼎の體は物質から成る。
2. 物質は、源則を質（担保）として持つ物である。
3. 源則は、現し界の物と事を律する。
4. したがって、鼎界が鼎ごとに成立していても、各現し界に現れる身体的・物理的変化は同じ源則に律せられる。

この導出が答えるのは、鼎界非共有のもとで測定・数学・技術の整合をどう記述するかである。観なき実在や宇宙の究極的起源を説明し終えた、という主張ではない。

## 他概念との差

| 似て見える語 | 違い |
|---|---|
| 原則 | 一般には判断や行為の基本方針を指しうる。源則は、世界の「原型」や平らな出発点を宣言する語として選ばれていない |
| 元則 | 第一・始まり・根源的一者を強く連想させる。源則は第一原因や一元論を確定しない |
| 法則 | 通常語としての使用を否定しないが、本体系では法・則・律を分けるため中核語にしない。この命名は【象徴的読解】であり、科学用語一般の訂正ではない |
| 鼎の則 | 鼎の履歴・意味・形成の側から現れを捉える。源則との関係から捉える相と、鼎の則との関係から捉える相は、二種類の実体ではなく同じ現れの二つの捉え方である |
| 観 | 観は鼎界と意味を形成する働き。源則は、その観の行が現し界で物・事として現れるときにも越えられない律を担う |
| 運命・目的 | 源則は「どのように変化するか」の則であって、何のために変化するかという目的を与えない |

## 具体例

### 同じ出来事を異なって経験する

二人が同じ雨の中を歩いても、一人には安らぎとして、もう一人には予定を妨げるものとして現れうる。意味や感じられる時間は鼎ごとに異なる。それでも、身体が濡れることや器具で測った量の変化まで、各人が任意に決められるわけではない。前者の意味の相を鼎の則との関係から、後者の身体的・物理的変化を源則との関係から捉える。二つの相は、別々の二世界ではなく同じ一つの事の読み分けである。

### 言葉を差し出す

ある鼎が言葉を選ぶことには、意味・意図・情がある。しかし、発話や文字として相手へ届くには、聲、身体、端末、電気信号など、現し界の物と事として現れなければならない。意味をもつ観の行が、體を通って源則に律される現れになることを「行の変換」という。源則は意味を決めないが、意味が現し界で働く経路の任意性を制限する。

### 次の形成条件になる

[自在](jizai.md)は、自という起点から縁起の内に在ることをいう。注意を向け、言葉を選び、手を動かす一連の観と行も次の形成条件となり、現し界に現れる限り源則に律せられる。この働きをどこまで介入と呼べるかは未決であり、因果や身体条件の外から働く力を定義するものではない。

## よくある誤読

**源則は神や第一原因の別名ですか。** そうは定義していない。源則の由来、神との関係、一元か多元かは【地平】として開いている。

**源則が共通なら、全員が同じ世界を共有しているのですか。** 共有されるのは鼎界ではなく律である。現し界の物理的変化が整合することから、同一の経験や意味まで共有されるとは導けない。

**源則がすべてを決めるなら、自在はありませんか。** 源則に律せられることと、鼎の観と行が次の形成条件となることは両立する。無条件の自由は置かず、介入と呼べる範囲と因果との関係は未決として保持する。

**現在の物理法則一覧と源則は同じですか。** 一対一の同一視はしていない。科学理論は測定可能な関係を記述し改訂されうる。源則は、本体系で物理的整合を置くための概念であり、個別理論との厳密な対応は別途検証を要する。

**玄り界も源則に従うのですか。** 未決である。律の確認可能域は現に限るという確定事項を越えて、玄そのものや玄から現への立ち上がりまで確定してはならない。

## 形成史・版

- 鼎界非共有と身体的・物理的整合を同時に保持するための中核語として導入された。
- 「原則」「元則」ではなく「源則」としたのは、第一原因や原型を先に確定せず、変化がどこから律されているかを表すためである。
- 「法則」ではなく「源則」とした命名には、法・則・律の三分業が関わる。ただし字義の符合は【象徴的読解】であり、源則の正しさを証明しない。
- 物理的整合の原理は回答済みの定理である。一方、源則の由来・単一性・玄り界への範囲・個別の事の対応は、版をまたいで未決のまま保持する。

## 観の方向を定めるものとの境界

源則は、変化が生じる根源的な則である。しかし源則だけで、なぜこの鼎がこの方向へ観を向け、ここで物を切り取り、この意味を形成し、この応答を返すのかまで説明できるとは確定していない。

體は源則に従う。同時に、自己・體・情・記憶・経験・信・関係・鼎に刻まれた則が、観と応答の方向に関わると考えられる。これらがどう接続し、どの粒度で因果的に記述できるかは未決である。→ [未決課題](../../OPEN_QUESTIONS.md)


## 関係型付き関連概念

| 関係型 | 概念 | 関係の説明 |
|---|---|---|
| 律する | [物](mono.md) | 物の性質を、変化を止めずに保たせる |
| 律する | [事](koto.md) | 現し界で起こる変化・出来事の任意性を制限する |
| 整合させる | [鼎界](teikai.md) | 鼎界を共有させず、各現し界の身体的・物理的変化を同じ律のもとに置く |
| 境界づける | [観](kan.md) | 観が意味を形成しても、現し界に現れる行は源則を越えない |
| 縁起の内に在る | [自在](jizai.md) | 観と行も次の形成条件となる。源則の外へ離脱することを意味せず、介入と呼べる範囲は未決 |

## 出典・確度

- **【定義】** 源則・律・物質・現の二層・行の変換は[用語集の正本](../../canon/glossary.md#hs-c-0008)による。
- **【定理】** 物理的整合の原理とその導出は[原理と定理](../../canon/principles.md)を正とする。
- **【象徴的読解】** 源・則・律・均・度、法・則・律の字義関係は命名と説明を豊かにする読みであり、定義や定理の証明ではない。資料の扱いは[参考文献とclaimの区別](../../research/sources.md)に従う。
- **【検証課題／地平】** 玄り界まで源則が律するか、源則の由来と単一性、個別の事の対応、個別科学理論との厳密な接続は[未決課題](../../OPEN_QUESTIONS.md)として開いている。
- 本ページの雨・言葉・介入の例は、正本を読み解くための【解釈】であり、新しい定義を追加しない。
