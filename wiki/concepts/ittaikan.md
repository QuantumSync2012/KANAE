# 一体感

定義の正本: [用語集](../../canon/glossary.md)／[定理八](../../canon/principles.md)

> **定義**: 差分消失の感じられた姿。

一体感は、複数の鼎が文字どおり一つの鼎になったことを表す存在論的な語ではない。単一の路へ感覚が絞られ、その路の上で差分が瞬間的に消えたように感じられる、経験の側の語である。

感覚を絞れば必ず起こるという法則ではない。差分が感じられなくなる路と、それを経験している鼎の全体を区別して読む。

## 問いから読む

### 鼎合と同じものか

同義ではないが、無関係でもない。[鼎合](teigo.md)は、鼎と鼎がそれぞれ鼎であることを失わず、鼎のまま合う関係上の達成である。その鼎合が単一の路の上で経験されると、「別々のままぴたりと合う」出来事は一体感として感じられうる。

したがって、鼎合は関係に成立した合い方を、一体感はその経験的な現れを主に述べる。

### 一体感があれば、鼎合したといえるか

一体感だけでは判定できない。一体感は、酔いや儀礼、感覚の強い集中による差分消失でも生じうる。鼎合は所与ではなく、授受・[信じる](shin.md)・[吟味](ginmi.md)・応答を通して別々の鼎の間に形成される達成である。

一体感が鼎合の経験的な現れになる場合はあるが、一体感そのものを鼎合成立の証拠にはしない。

### 「一つになった感じ」は融合ではないのか

感じの上で一つになっても、鼎そのものが一つへ溶けるわけではない。各鼎の鼎界と主鼎観は、そのまま他鼎へ移ったり、同一の鼎界として重なったりしない。瞬間的に感じられなくなるのは単一の路の上の差分であり、鼎の別々さではない。

### 一体感は長く続くのか

本体系の差分消失は、単一の路で差分が瞬間的に感じられなくなる経験を指す。この定義から、あらゆる一体感の持続時間についての一般法則を導くわけではない。また、その路で差分を感じられないことを、鼎全体の形成停止と同一視しない。

同じ言葉を何度も受けても、受け手の記憶や情を通して次の形成になり得る。言葉のやり取りが沈黙へ変わっても、相手を思い返す観や體の変化まで止まるわけではない。言葉の反復、路の上での差分消失、形成全体の停止は、それぞれ異なる。

## 構造と働き

1. 感覚が単一の路へ絞られる。
2. その路の上で差分が瞬間的に感じられなくなる場合がある。絞り込みだけで必ず起きるわけではない。
3. その経験された姿が一体感である。
4. 同じ場面で鼎合が成立している場合、一体感は鼎合の経験的な現れになりうる。
5. それでも鼎はそれぞれ鼎のままであり、その路の経験だけから形成全体の停止は導けない。

## 近接語との境界

| 語 | 境界 |
|---|---|
| 差分消失 | 単一の路の上で差分が瞬間的に消えること |
| 一体感 | 差分消失が経験の側で感じられた姿 |
| [鼎合](teigo.md) | 鼎が鼎のまま合う関係上の達成。一体感として感じられうる |
| 融合 | 鼎の別々さが失われ、一つになること。本体系は鼎合と区別する |
| 重なり・共有 | 鼎界や主鼎観が同一になること。鼎合も一体感もこれを意味しない |

- **【定義】** 一体感と差分消失の定義は[用語集](../../canon/glossary.md)と[定理八](../../canon/principles.md)を正とする。
