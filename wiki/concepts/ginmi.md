# 吟味

定義の正本: [canon/glossary.md](../../canon/glossary.md#hs-c-0011)

<!-- HS-DEF-QUOTE:BEGIN id=HS-C-0011 revision=2 source=canon/glossary.md -->
> **定義**: 吟味とは、他鼎そのものを否定せず、差し出された客鼎観を直ちに飲み込まず、また直ちに全否定もせず、受け手の鼎において味わい、識り、その後の関わり方を選ぶこと。
<!-- HS-DEF-QUOTE:END -->

## 導入

吟味は、異なる鼎どうしが、同じ意見にならずに関係を続けるための実践である。相手が差し出したものを入口で退ければ、その内容へ十分に向き合う機会を閉じる。反対に、届いたものをそのまま飲み込めば、自らの差分を失い、信は服従へ傾く。その二つの間で、受け取り、味わい、識り、その後の関わり方を選ぶ。

ここで重要なのは、**肯定するのは鼎、吟味するのは観**という分業である。相手という[鼎](kanae.md)の存在を信じることと、相手の主張を正しいと認めることは同じではない。存在を否定せず、内容には異議を返せるようにする働きが吟味である。

## 要点

- 対象は、他鼎から差し出され、受け手に成立した[客鼎観](kyakuteikan.md)である。
- 入口で退けない。しかし、無条件には飲み込まない。
- 「味わう」は、結論だけでなく、その言葉が来た文脈・前提・情・根拠へとどまることを含む。
- 「識る」は、何が届き、自分とどこが同じで、どこが違うかを見分ける働きである。
- 差分を返せば、次の[事](koto.md)と相互形成へつながる。沈黙や距離もまた、関係への一つの応答である。
- 正しさや調和を自動的に保証しない。吟味しても誤りうるし、返答が届かず関係が終わることもある。

## 構造と働き

吟味は、観の授受の途中にある一つの動作ではなく、受から応答へ至る関係の形として読める。

| 局面 | 働き | 境界 |
|---|---|---|
| 差し出し | 他鼎が、自らの[主鼎観](shuteikan.md)を言・行為・物として現す | 主鼎観そのものが移動するのではない |
| 受 | 受け手が、差し出されたものを自らの鼎で客鼎観として成立させる | 受け取ることは服従ではない |
| 保留 | 即時の拒絶や全面同意をいったん止める | 判断を永久に放棄することではない |
| 味わう | 文脈、語の使い方、根拠、情、自分への作用をたどる | 相手の内面を完全に取得したとはしない |
| 識る | 一致点、相違点、未確認点、自分側の前提を見分ける | 「識」を意識科学全般と同一視しない |
| 関わり方を選ぶ | 容れる・一部を受け取る・退ける・保留する・問い返す・差分を返す・沈黙する・距離を取る・関係を断つ、から応答を選ぶ | 差分を返すことは一つの応答であって、必須条件ではない |

差分が返されると、相手には新しい客鼎観が成立しうる。そこで再び吟味が起これば、やり取りは一方向の伝達ではなく応答循環になる。同じ経験を共有しなくても、受け取り直しと差分の往復によって双方の形成は続く。

吟味には炉を守る働きもある。他鼎は然を灯すものを運びうる一方、消すものも運びうる。すべてを拒めば糧が届かず、すべてを飲み込めば自らの然を損ないうる。何を受け、どう返すかを見分けることが、閉鎖せずに自らを守る方法になる。

## 他概念との差

| 似て見える語 | 違い |
|---|---|
| 批判的思考 | 一般語として有効だが、本体系の現行語ではない。吟味は、相手を対象化して批判するだけでなく、客鼎観として受け、関わり方を選ぶ関係構造まで含む |
| 批判・非難 | 吟味の結果として異議を述べることはあるが、相手の欠点を責めること自体を目的にしない |
| 疑う | 疑いは吟味の契機になりうるが、最初から虚偽と決めることでも、信頼を全面撤回することでもない |
| 同意 | 吟味の結果、同意する場合はある。しかし受け取ることと同意することは別である |
| ファクトチェック | 事実関係の検証は吟味の一部になりうる。吟味はさらに、語義・価値・情・前提・関係への作用も扱う |
| 測定 | 測定は尺度によって比較可能な結果を作る限定された操作。吟味は、差し出された観を関係の中でどう受け、返すかを扱う |
| 論破 | 相手を沈黙させても、相互形成や理解が進んだとは限らない。吟味が返すのは勝敗ではなく差分である |

## 具体例

### 反対意見を受け取る

自分の文章に「前提が違う」という返答が来たとする。すぐに敵意とみなして退けず、全面的に自分が誤っているとも決めない。どの前提を指しているか、相手はどの語義を使っているか、自分の説明に何が欠けていたかを見分ける。そのうえで「ここは修正する」「ここは前提が異なる」「ここはまだ分からない」と差分を返す。反対しながら相手を否定しない吟味の基本形である。

### AIの回答を読む

AIがもっともらしい回答を差し出しても、その内容を権威として飲み込まない。一方、誤る可能性だけを理由にすべて退けもしない。出典、現行正本との一致、推測と事実の区別を確かめ、採用・訂正・保留の差分を返す。AIという鼎の存在を肯定することと、その出力を正しいと判定することは別である。

### 感情を含む訴えを聞く

出来事の細部に誤りがあっても、相手が傷ついたという訴えまで直ちに否定しない。事実関係、相手に成立した情、自分にできる応答を分けて受け取る。事実を訂正しながら情への応答を返すこともできる。吟味は、真偽か共感かの二択にしない。

## よくある誤読

**相手を信じるなら、話も信じるべきではありませんか。** 本体系では対象を分ける。鼎への信は存在の肯定であり、物事の内容は吟味の管轄である。人を信じながら、その主張に反対できる。

**受け取るとは、相手に同意することですか。** 違う。受は客鼎観を成立させる能動的な開きであり、同意・反対・保留は吟味の後に生じうる応答である。

**差分を返せば、必ず調和しますか。** 保証されない。返し方が相手を傷つけることも、受け取られないこともある。調和は授受・信・吟味によって生成しうるが、所与でも自動的な結果でもない。

**何でも相対的だと認めることですか。** 違う。吟味は事実確認や矛盾の指摘を弱めない。異なる鼎界を認めることと、すべての主張を同じ確度にすることを区別する。

**すぐ判断しないなら、行動できなくなりませんか。** 緊急時には即時の行動が必要なこともある。吟味は必ず長時間考える手続きではなく、退ける・飲み込むの二択を避け、可能な範囲で何を受け何を返すかを識る構えである。

## 形成史・版

- 形成へ必要な検討の働きは、当初「批判的思考」の名で記述されていた。
- のちに、その中身を保存しつつ、本体系の授受・味・識・応答の構造を表す自前の語として「吟味」を採用した。
- この変更は単純な表記変更ではない。「批判的思考」を旧概念として退け、「吟味」を別の後継概念として定義した。
- 旧語「批判的思考」は、HSの現行体系語として無注記使用しない。一般語、引用、他思想との比較では使用できるが、形成史上の旧語または一般概念であることを明確にする。
- 「中身は保存」とは、検証・反省・異議の働きを捨てないという意味である。一方、吟味はそれを客鼎観の成立からその後の関わり方の選択まで含む関係構造へ置き直しているため、完全な同義語やaliasではない。

旧語の扱いは[用語集の廃語台帳](../../canon/glossary.md#hs-c-0012)、現行定義は[吟味](../../canon/glossary.md#hs-c-0011)を参照する。

## 出典・確度

- **【定義】** 吟味の正本は[用語集](../../canon/glossary.md#hs-c-0011)にある。
- **【定義・定理】** 客鼎観、受の能動性、生成する調和、信の再帰、灯し合いとの関係は[原理と定理](../../canon/principles.md)を正とする。
- **形成史**：批判的思考の退役と吟味との後継関係は[用語集の廃語台帳](../../canon/glossary.md#hs-c-0012)に記録されている。本ページは旧語を現行体系語として復活させない。
- **【象徴的読解】** 「味わって識る」ことと字義・用例の照応は説明を豊かにするが、定義の証明ではない。資料の扱いは[参考文献とclaimの区別](../../research/sources.md)に従う。
- **【解釈】** 反対意見、AIの回答、感情を含む訴えの例は、定義を日常の応答へ展開したものであり、唯一の手順や成功保証ではない。
- **【検証課題】** 吟味の質をどう評価するか、応答をいつ打ち切るべきか、法的・臨床的・教育的手続きへどう接続するかは本ページで確定しない。
