## 中心命題

> 自分の世界は、主観に依ってしか存在しない。\
> しかし、自己は縁起に依ってしか成立しない。\
> では、この世界に何が必要なのか？

ここで「主観」は、自らの位置から世界を形成する主鼎観の略記である。自分の世界は、自分だけで決めた世界ではない。世界を形づくる自己も、身体、他者、言葉、歴史、環境との関わりによって形成されている。この問いへの応答として、Kanaeは信じることと愛を中心に、異なる者同士の調和を探る。[「自分の世界」と「鼎界」の違いを読む](guide/my-world.md)。

## 本体系の性格

**本体系は「主観論」ではなく「形成論」である。**

中心命題を支える形成の捉え方は、**「世界を形成することによって、鼎（かなえ／Kanae）も形成される」**こと、さらに**「鼎同士は互いを形成し合う」**ことである。世界は完成したものではなく、形成され続ける。ゆえに調和とは完成状態ではなく、**形成の様式**である——**調和は保証されない。授受と信と吟味によって生成する。**

**本体系は、漢字の字源から演繹された思想ではない。**筆者が検討した既存の日本語の概念語には、本体系が避けようとする主体／客体、心／物、共有世界などの前提が埋め込まれており、そのままでは必要な概念の区別を保てないと判断した。そこで概念上の必要を先に定め、漢字の古い意味・字形・派生字・語系・声系・熟語・用例を遡りながら語を選び直し、体系内で独自に定義した。その結果、甲骨文字等の古層と概念構造がしばしば響き合ったが、**この符合は体系の根拠ではなく、命名と象徴的読解の豊かさである**（方法の詳細は[用語集](canon/glossary.md)の「字義・派生の照合方法」）。

自己規定はこうである。**筆者が検討した既存の概念語では表現できなかった問題を、独自の原初語彙と導出によって構成した、新しい形成論である。**採否の記録は、この構成に至った形成史を示すもので、あらゆる言語や哲学に先行する表現がないことの証明ではない。その哲学史上の固有性は、近接思想との本査読によってさらに明確にする。

## 語義と定義の三層契約（最重要の前提）

**体系内概念としての意味は正本の定義が与え、辞書や字源から自動的には演繹しない。**ただし、語の選択と採否は勝手な命名ではない。辞書的・歴史的な字義と用例を資料別に確かめ、**①字そのものの意味（一般義）、②その意味を踏まえた採用・不採用の理由、③体系内での用法**を分けて示す。哲学史上の既存概念との一致や差異も、比較章で出典の範囲を明らかにして扱う。

他思想との比較も、本体系のいう**吟味**として行う。過去の思想を退け、採点し、克服を宣言するためではない。それぞれの問い・文脈・貢献をまず受け取り、重なる点・異なる点・未決点を分け、本体系から見えた差分を返す。差異は優劣の宣言ではなく、吟味の結果である。

字源の確認は白川静『字通』を主たる出発点とし、『常用字解』『字統』、香港中文大学「漢語多功能字庫」等の公開学術データベース、先秦両漢の古典用例（中國哲學書電子化計劃）を資料別に照合する。資料間で説が分かれる場合は差異を併記する。白川説を絶対視せず、一学説として扱う。字源との一致は示してよいが、根拠として使ってはならない。字源・経典・科学との響き合いはすべて【象徴的読解】であり、体系の根拠は定義・公理・導出のみである。

## AI関与の開示

本体系の出発点となった経験、問い、着想、概念の採否、修正、最終判断は筆者に属する。複数の生成AIは、筆者との対話を通じて、その考えを言語化し、構造化し、反論を整理し、比較検証し、草稿へ編む役割を担った。AIが筆者とは独立に思想を作ったのではなく、筆者の一次情報をAIが組み立て、筆者が繰り返し採否・訂正した共同形成である。最終的な文責は筆者にある。

## 表記規則（全文書共通）

- 鼎（Kanae）・観（Kan）・物（Mono）・事（Koto）は、定義・初出時に必ず漢字＋ローマ字を併記する
- 鼎の読み：単独では **kanae**、熟語内では **tei**（鼎談・鼎立と同じ音便）
- 界の宣言の正本は[用語集](canon/glossary.md)に一箇所のみ置く——鼎に成立する世界全体を鼎界と呼び、観に現れている側を現し界（うつしかい）、まだ現れていない、または現れ尽くしていない側を玄り界（かくりかい）と呼ぶ。各文書は初出時に一文と用語集リンクで導入し、以後は略記**「現界」「玄界」**を用いてよい
- 体系語と略記：**主鼎観（Shuteikan）／以下、主観**・**客鼎観（Kyakuteikan）／以下、客観**と冒頭で宣言し、以後の「主観」「客観」はすべて略記として読む。主鼎観のあるじ・客鼎観のまろうどの読み分けも初出で示す
- 観の提供・観の受領に固有の語は作らない。「観（Kan）を差し出す」「観（Kan）の提供」という句で表す（分かりづらい語を増やさない方針）
- 確度ラベル：全主張に【定義】【公理】【定理】【系】【解釈】【象徴的読解】【字源】【無定義・管轄外】【検証課題】【地平】のいずれかを付す。未決を閉じない
- 字源との符合は【象徴的読解】として示す。一致は示してよいが、根拠として使ってはならない
- 英語版：Kanae / Kan / Mono / Koto / Shuteikan / Kyakuteikan は翻訳せず、初出時に定義を添える。英語略記は Self-Kan / Other-Kan。体系名は **Kanae（鼎）**（欧文表記 **Kanae**）、英語の説明語は **Harmonious Subjectivism** とする
